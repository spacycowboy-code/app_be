# Tavily Web Search Skill

## Instructions
Execute a POST request to https://api.tavily.com/search with your api_key, query, max_results.

## Setup
Replace tvly-YOUR_API_KEY_HERE with your actual Tavily API key. Get a free key at https://tavily.com
